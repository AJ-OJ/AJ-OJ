## Projects

**[artwork-precheck-agent](https://github.com/AJ-OJ/artwork-precheck-agent)**
A TypeScript agent that pre-checks sticker artwork before a human proofer sees it. Measurable print rules are plain code, Claude's vision and tool use handle what rules cannot, and the model is only allowed to make outcomes stricter. It has a rules-only fallback and a test suite that replays scripted model behaviour, including bad behaviour.
